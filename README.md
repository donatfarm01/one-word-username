One word, one username, one reward: this entry sends the entrant's own make.fun username, donatfarm01, and nothing else. A judge model reads two usernames at a time and picks the one that feels funnier or more interesting; a genuine handle beats any invented word, so the entry is the handle itself.

## Run it

```sh
python3 main.py
```
