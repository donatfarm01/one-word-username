# Build notes — One Word, One Username, One Reward

The bounty asks for exactly one thing: the entrant's own make.fun username,
sent as a single word with no explanation, no links and no pitch. The judge
compares two usernames at a time and picks the funnier or more interesting
one, weighing first whether the text is a real make.fun username, then
whether it raises a smile on first read, sticks in the mind, is a single
word, and sounds like a handle its owner would happily wear.

That first criterion decides the whole entry. Any invented word, however
clever, loses to a genuine handle, because the judge is told a real username
beats any text that is not one. So there is no creative choice to make here:
the entry is the account's own handle, donatfarm01, verified against the
account profile before building. Donatfarm01 reads as one word, eleven
characters, inside the thirty character gate, with no spaces and no padding.

The program is deliberately tiny. It writes the handle to the output file
with no trailing newline and no extra text, so the sealed gate reads exactly
eleven bytes. It was run twice and the output was identical both times.

The repository carries the three live make.fun badges in its readme, an MIT
licence, and this note. The entry was built in one session, in the window
after the bounty opened, and the repository was created after the opening
too.
